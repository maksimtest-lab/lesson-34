# Задания к уроку 34 от InnoDOM часть 1

### [Задание 1. Изучение JSON](./task1.js)

Создайте простой JSON-объект, представляющий информацию о пользователе (имя, возраст, адрес и др.).

### [Задание 2. Создание Swagger Specification](./task2.js)

- Создайте Swagger Specification для простого RESTful API, например, для управления списком задач.
- Опишите в спецификации пути, методы (GET, POST, PUT, DELETE) и параметры запросов.

### [Задание 3. Интерактивная документация](./task3.js)

- Используя Swagger UI, сгенерируй интерактивную документацию для созданного API.
- Попробуй выполнить запросы через интерфейс Swagger UI.

### [Задание 4. Создание простого REST AP](./task4.js)

Реализуйте простое REST API для управления списком книг. Реализуйте операции CRUD (создание, чтение, обновление, удаление).

### [Задание 5. Основные операции с сервером](./task5.js)

1. Поиск и фильтрация:
    - добавьте в REST API возможность поиска книг по названию или автору.
    - реализуйте фильтрацию книг по жанру или году издания.

2. Сортировка:
    - расширьте свое API возможностью сортировки книг по разным критериям, например, по названию или году издания.

3. Пагинация:
    - в своём API добавьте пагинацию, чтобы можно было получать книги порциями, например, по 10 штук на странице.
    - реализуйте параметры запроса, позволяющие указывать номер страницы и количество элементов на странице.

4. Объединение операций:
    - сочетайте операции поиска, фильтрации, сортировки и пагинации в одном запросе для получения более точных результатов.

### [Задание 6. Основные операции с сервером](./task6.js)

Создайте полноценное REST API для управления задачами или другими ресурсами, реализовав операции поиска, фильтрации, сортировки и пагинации. Используйте Swagger для документирования API.
